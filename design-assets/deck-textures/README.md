# Nana grid-free textures

Current cream, lilac and purple atmospheric backgrounds. Every composition preserves the oversized translucent bubble and removes the square grid motif.

Each background is available as:

- a full-resolution PNG for design work;
- a lightweight 1280x720 JPEG ending in `-deck.jpg` for slides and previews.

Use one dominant atmospheric texture per surface. Do not add a grid over these files.
