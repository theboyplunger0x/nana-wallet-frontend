# Nana glass bubbles

Transparent raster versions of the bubble system used across the Nana landing and pitch materials.

- `nana-glass-bubble.png`: high-resolution source for compositing and new layouts.
- `nana-glass-bubble-deck.png`: lighter version for slides and quick web mockups.

Use bubbles to create depth, mark a state or communicate progression. Keep them soft, translucent and partially cropped when used as atmosphere. The live landing also includes editable CSS versions in `src/styles.css`.
